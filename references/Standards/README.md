# PCB Design Standards

## Overview

This directory contains reference material and engineering notes that were used during the design of this PCB.

These documents are **not official IPC publications**. Instead, they are concise engineering summaries and design checklists prepared for this project based on widely accepted PCB design practices and publicly available resources.

## Contents

### IPC-2221_Overview.pdf

A summarized overview of common PCB design principles inspired by IPC-2221 recommendations, including:

- PCB stack-up considerations
- Trace width selection
- Copper clearance
- Component spacing
- Thermal relief
- Ground planes
- Silkscreen placement
- Via usage
- Design Rule Check (DRC)

### PCB_Design_Checklist.pdf

A practical checklist used before generating manufacturing files.

## Purpose

These documents serve as project documentation and demonstrate the engineering considerations taken during PCB development.
